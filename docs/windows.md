측정 2026-10-01 · 일본판 디스크의 일본어 원문 전부(`tools/survey_lines.py` → `work/lines_jp.tsv`) + 측정판 v0.0.3 돌핀 확인
폭 = 폰트 폭 표로 계산한 픽셀. 폭 표는 시스템 묶음(`JBtPakJS.bin` 등) 2번 블록이고, 형식은 **[개수 u32][기본 폭 1바이트=28][글자별 폭 × 개수]**입니다.
- 처음 측정 때는 기본 폭 1바이트를 빠뜨려 폭이 한 칸씩 밀려 있었습니다. 측정판 결과와 폰트 그림 대조로 바로잡았습니다.
- 주요 폭: 한글 26px(넣는 값), 공백 10px, 마침표 7px, 숫자 9~17px, 전각 부호 27~28px.

- 방 조사 창은 **자동 줄바꿈이 됩니다**. 공백에서 꺾고, 공백이 없으면 글자 단위로 꺾습니다. 그래서 번역문에 줄바꿈을 직접 넣지 않아도 됩니다. 일본어판은 자동 줄바꿈 폭에 맞춰 손으로 줄을 나눴습니다(원문 최대 622px).
- 컷신 자막은 두 줄까지 됩니다. 일본어판은 모두 한 줄이었지만 한국어는 두 줄을 쓸 수 있어서, 영어 원문 길이를 받아낼 여유가 있습니다.
- 실시간·음성 자막, NPC 대사, 아이템 설명 등은 자동 줄바꿈·두 줄 여부를 확인하지 않았습니다. 원문 한계로 두고, 넘치는 번역이 많으면 그때 측정판으로 확인합니다.

- 변수 자리는 검사기에서 한글 6자(156px)로 가정합니다. 실제 값의 최대 길이는 4단계에서 정합니다.

## 검사 도구

`tools/check_overflow.py <번역.json>`: 항목마다 `kind`(창 종류)를 붙이면 검사합니다. 창 종류는 `kind_of(분류, 블록, 라벨)`로 자동으로 정합니다.
- 자동 줄바꿈 창(방 조사 창): 게임과 같은 방식으로 꺾은 뒤 줄 수를 봅니다. 측정판 화면과 꺾이는 자리가 똑같았습니다.
- 그 밖의 창: 줄마다 폭(px)과 줄 수를 봅니다.
