이터널 다크니스 한글 패치 v0.2.1 (GameCube)
=============================================

일본판 「이터널 다크니스 ～초대받은 13인～」 이미지에 적용하는 한글 패치입니다.
게임 데이터는 들어 있지 않으며, 직접 소유한 디스크에서 만든 이미지가 필요합니다.


[사용법]

  1. 이 폴더에 원본 이미지를 넣고 「패치하기.bat」을 더블클릭합니다.
     또는 원본 이미지 파일을 「패치하기.bat」 위에 끌어다 놓습니다.
  2. 끝나면 원본과 같은 폴더에 「Eternal Darkness (Korean).iso」가 생깁니다.
     원본 파일은 그대로 남습니다.

  처음 실행할 때 Windows가 경고하면 「추가 정보 → 실행」을 누르세요.
  Windows 10 이상에 기본으로 들어 있는 PowerShell을 사용합니다.
  원본 크기만큼(약 1.4GB) 빈 공간이 필요합니다.

  결과 파일 이름을 바꾸려면 명령줄에서 두 번째 인자로 지정합니다.
    패치하기.bat "원본.iso" "D:\Games\이터널 다크니스 한글.iso"


[원본 이미지]

  게임: 이터널 다크니스 ～招かれた13人～ 일본판 (게임 ID GEDJ01)

  패처가 게임 파일 하나하나를 원본과 비교하므로,
  덤프 방식에 따라 ISO 전체 MD5가 달라도 게임 파일만 같으면 적용됩니다.
  참고: Redump 정본 ISO는 1,459,978,240 바이트, MD5 ae427c8f680f7c9dbb2a9b17c7583de6 입니다.
  정본에 적용하면 끝에 「정본(Redump) 원본 기준 결과와 일치합니다」가 나옵니다.

  지원 형식          결과
  ---------------    ------
  ISO, GCM           ISO
  CISO, WIA, WDF,    ISO (동봉한 wit으로 ISO로 바꾼 뒤 적용)
  GCZ
  RVZ                지원 안 함 → Dolphin에서 ISO로 변환한 뒤 적용
                     (게임 우클릭 → 변환 → ISO)
  NKit               지원 안 함 → NKit 도구로 원래 ISO로 되돌린 뒤 적용

  북미판·유럽판, 이미 한글 패치를 적용한 이미지에는 적용되지 않습니다.
  항상 일본판 원본에 적용하세요.


[오류 메시지]

  ~이(가) 아닙니다. 읽은 게임 ID      다른 게임이나 다른 지역판입니다.
  원본의 파일 목록(FST)이 다릅니다    이미 패치한 이미지이거나 다른 판입니다.
  원본 게임 파일이 다릅니다           이미 패치한 이미지이거나 손상된 덤프입니다.
  이미지 크기가 작습니다              잘린 덤프이거나 NKit 이미지입니다.
  RVZ는 지원하지 않습니다             위 [원본 이미지] 표를 참고해 ISO로 바꾸세요.
  ISO로 변환하지 못했습니다           이미지가 손상됐거나 지원하지 않는 형식입니다.


[실행]

  - Dolphin에서 확인했습니다.
  - 게임 설정의 언어는 「한국어」(일본판의 「日本語」 자리)로 두세요.


[알려진 한계]

  - 오프닝 영상 타이틀 부제(일본어)는 영상 안에 그려져 있어 그대로 두었습니다.
  - 숫자만 있는 그림(16:9, 4:3)과 일본판에서도 영어였던 디자인 글자
    (Press A to Continue 등)는 그대로 두었습니다.

  - 게임 이름·캐릭터·로고와 상표·저작권은 각 권리자에게 있습니다.
  - 게임 데이터는 포함되어 있지 않습니다. 정품을 소유한 사람이 자신의 디스크로 만든 이미지에만 적용하세요.
